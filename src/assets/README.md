# Assets Folder

## Resume PDF

Place your resume PDF file here with the name: **`resume.pdf`**

The download button in the Resume section is already configured to download this file.

### File Path:
```
src/assets/resume.pdf
```

### How it works:
When users click the "Download CV" button, the browser will automatically download the PDF file with the name `Ankush_Pathania_Resume.pdf`.
